## 概述 / Overview

本章节介绍 Go 语言的输入输出和网络编程，包括：

- **文件 IO**: 读写文件、bufio 缓冲、文件信息
- **目录操作**: 创建、遍历、删除目录
- **io 接口**: Reader, Writer, Closer 等核心接口
- **HTTP 客户端**: 请求发送、响应处理、超时设置
- **HTTP 服务器**: 路由、中间件、处理器
- **HTTP/2**: 高级配置、TLS
- **网络编程**: TCP/UDP 编程基础
