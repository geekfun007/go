                           💡 关键要点 / KEY POINTS
================================================================================

核心差异:
  Go:
    - CSP 模型 (Goroutine + Channel)
    - 真正并行执行
    - 抢占式调度
    - 简单直接

  Python:
    - 事件循环 + 协程
    - 单线程并发
    - 协作式调度
    - 显式控制

设计模式:
  Go:
    - Worker Pool (工作池)
    - Pipeline (流水线)
    - Fan-out/Fan-in (扇出扇入)
    - Semaphore (信号量)

  Python:
    - 并发请求
    - 异步生成器
    - 异步上下文管理器
    - 异步队列

性能对比:
  场景: 1000 个并发 HTTP 请求
  Go:    2.5s, 100MB, 多核 80%
  Python: 3.0s, 50MB, 单核 95%

选择建议:
  选 Go:   高性能、CPU密集、真正并行
  选 Python: I/O密集、快速开发、丰富生态
