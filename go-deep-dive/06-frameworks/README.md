## 概述 / Overview

本章节介绍 Go 语言中常用的数据库操作和框架使用，包括：

### 数据库 / Database
- **GORM**: Go 语言最流行的 ORM 框架，简化数据库操作
- **MySQL**: 直接使用 database/sql 和 MySQL 驱动
- **Redis**: 高性能内存数据库，支持多种数据结构

### RPC 框架 / RPC Frameworks
- **Thrift**: Apache Thrift RPC 框架
- **Kitex**: 字节跳动开源的高性能 RPC 框架

### HTTP 框架 / HTTP Frameworks
- **Hertz**: 字节跳动开源的高性能 HTTP 框架

### 部署与容器化 / Deployment & Containerization
- **Docker**: 容器化部署，Dockerfile 编写
- **Docker Compose**: 多容器编排，开发环境搭建
