## 概述 / Overview

本章节介绍 Go 语言的函数和逻辑控制，包括：

- **函数基础**: 声明、多返回值、可变参数
- **闭包**: 匿名函数、变量捕获、状态封装
- **方法**: 值接收者、指针接收者、方法提升
- **高阶函数**: Map, Filter, Reduce 等函数式编程
- **函数选项**: 灵活的配置模式
- **递归**: 基本递归、尾递归、记忆化
- **defer/panic/recover**: 资源清理、错误恢复
