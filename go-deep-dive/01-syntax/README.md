## 概述 / Overview

本章节介绍 Go 语言的基础语法，包括：

- **程序结构**: package 声明、import 导入、main 函数
- **变量声明**: var 关键字、短变量声明、零值
- **常量**: const 关键字、iota 枚举
- **控制流**: if/else、for 循环、switch 语句
- **指针**: 内存地址、解引用、new 函数
- **defer**: 延迟执行、资源清理
