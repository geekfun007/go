## 概述 / Overview

本章节介绍 Go 语言的数据类型和方法，包括：

- **数值类型**: int, float64, bool 等基本类型
- **字符串**: 不可变 UTF-8 字节序列，strings 包操作
- **日期时间**: time 包，格式化与解析
- **正则表达式**: regexp 包
- **数组与切片**: 固定长度数组和动态切片
- **迭代器**: Go 1.23+ 的 iter 包和 slices 包迭代器
- **映射**: key-value 数据结构
- **结构体**: 自定义复合类型
- **JSON**: 序列化与反序列化
- **接口**: 多态和抽象
- **错误处理**: error 接口、包装、panic/recover
